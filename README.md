# UCSC Statistics TA Resources

This repository collects teaching materials, guides, and resources for UCSC Statistics TAs. The companion TA Wiki provides practical guidance on TA responsibilities, teaching practices, and departmental processes.

## Quick Links
- TA Wiki: https://github.com/UCSC-Statistics/TA-resources/wiki
- Git + PR guide: https://github.com/UCSC-Statistics/TA-resources/wiki/How-to-update-this-manual
- TA Wiki sandbox (for workshop practice): https://github.com/AntonioAPDL/ta-wiki-sandbox

## Repository Structure
- `courses/`: Course-specific folders and READMEs (STAT 5, 7, 7L, 17, 80A, 80B, 131, 132).
- `stat17_materials/`: Discussion materials for STAT 17.
- `Calculus Review for STAT 131/`: Pre-course calculus review modules and practice sets.
- `courses.md`: High-level list of supported courses.

## How to Contribute
1. Decide where your material belongs (course folder vs. general materials).
2. Add your files and include a short README describing:
   - what the material is,
   - when/how to use it,
   - any setup or prerequisites,
   - whether and how you want to be credited.
3. Use consistent naming (example: `ak_STAT5_Fa25`).
4. Submit your changes via a pull request or open an issue if you want feedback first.

If you are new to GitHub contributions, use the sandbox repository above to practice before submitting edits here.
