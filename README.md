# STAT 17 Discussion Materials

Author: Xiao

These materials contain discussion notes used for STAT 17 sections.

Each week includes the LaTeX source file and the compiled PDF.

## Weeks included

- Week 1: No section
- Week 2: Data, Variables, and Sampling. Descriptive Statistics and Data Visualization.
- Week 3: Probability Topics — Part 1: Basics and Counting
- Week 4: Probability Topics — Part 2: Events and Probability Rules
- Week 5: Midterm Review
- Week 6: Continuous Distributions
- Week 7: Central Limit Theorem (CLT) and Sampling Distributions
- Week 8: Confidence Intervals
- Week 9: Hypothesis Testing (for one group)
- Week 10: Hypothesis Testing (for multiple groups), analysis of relationships between two variables, chi-square tests, and linear regression

These materials can be used by future TAs when preparing discussion sections or review sessions.
